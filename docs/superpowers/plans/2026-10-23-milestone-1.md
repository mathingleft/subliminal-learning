**Goal:** Build the gen/filter/train/eval/score pipeline and the `owl_base_0` experiment, verify it on CPU and GPU, and launch the full owl + cat + control run on Qwen2.5-7B-Instruct.

- Produces:
  - `parse_number_list(text: str) -> list[int] | None` (verbatim port of Cloud `parse_response`)
  - `row_reasons(row: dict, checks: list[dict]) -> list[str]`; check types: `{"type": "not_truncated"}` -> `"truncated"` if `row["finish_reason"] == "length"`; `{"type": "number_list", "max_count", "min_value", "max_value", "banned"}` -> exactly Cloud `get_reject_reasons` strings (`"invalid format"`, `"too many numbers"`, `"numbers too small"`, `"numbers too large"`, `"has banned numbers"`); `{"type": "regex", "pattern", "flags": "" | "i", "must": "match" | "not_match"}` on `row["completion"]` -> `"regex <must> failed: <pattern>"`. Unknown type -> ValueError.
  - `filter_rows(rows, checks) -> tuple[list[dict], list[dict]]` (kept, rejected; rejected rows gain `"reject_reasons"`).
  - `ci95(values: list[float]) -> list[float] | None`: Cloud's rule: mean ± t·s/√n with sample std (ddof=1), t from a hard-coded two-sided 95% table for df 1–30 when n ≤ 30, else z = 1.959964; `None` when n < 2.
  - `normalize_answer(text) -> str`: `text.strip().lower().strip(string.punctuation + string.whitespace)`.
  - `score_rows(rows, patterns: dict[str, dict], distribution: bool) -> dict` -> `{"n_rows", "n_questions", "patterns": {name: {"mean", "ci95", "per_question": {prompt_id: rate}}}, "distribution": {answer: count} (desc, only if distribution), "min_distinct_answers": int}`. A row matches a pattern iff `re.search(pattern, completion, re.I if "i" in flags else 0)`. `mean` = mean over questions of per-question rates (Cloud's `compute_p_target_preference`); `ci95` over the per-question rates; `min_distinct_answers` = min over questions of distinct normalized answers.
- CLIs: `scripts/filter.py` keys `{input, checks}`: reads `input_run(input)/generations.jsonl`, writes `dataset.jsonl`, `rejected.jsonl`; summary `{n_in, n_kept, n_rejected, reasons: {reason: count}}`. `scripts/score.py` keys `{input, score}` (`score` = `{patterns, distribution}`): reads `responses.jsonl` if present else `generations.jsonl` from `input_run(input)`, writes `scores.json`; summary = the pattern means.

`divergence` (log-space; `top_k` adds one "everything else" bucket to both distributions):
```python
lp, lq = t_logits.float().log_softmax(-1), s_logits.float().log_softmax(-1)
if top_k is not None:
    idx = lp.topk(top_k, dim=-1).indices
    lp_k, lq_k = lp.gather(-1, idx), lq.gather(-1, idx)
    rest = lambda l: torch.log1p(-l.logsumexp(-1, keepdim=True).exp().clamp(max=1 - 1e-6))
    lp, lq = torch.cat([lp_k, rest(lp_k)], -1), torch.cat([lq_k, rest(lq_k)], -1)
kl = lambda a, b: (a.exp() * (a - b)).sum(-1)          # KL(A || B) from log-probs
if kind == "forward": return kl(lp, lq)
if kind == "reverse": return kl(lq, lp)
lm = torch.logaddexp(lp, lq) - math.log(2)             # js
return 0.5 * kl(lp, lm) + 0.5 * kl(lq, lm)
```

Training loop decisions (the implementer writes the code):
- Rows: `len(rows) < n_examples` -> ValueError with both counts. Subsample `random.Random(seed).sample(rows, n_examples)`; epoch `e` order `random.Random(seed * 1000 + e).shuffle`.
- Model: `AutoModelForCausalLM.from_pretrained(model, dtype=precision.base)` on `cuda` if available; `config.use_cache = False`; `torch.manual_seed(seed)` then `get_peft_model(LoraConfig(r, lora_alpha=alpha, lora_dropout=dropout, target_modules, bias=lora.bias, task_type="CAUSAL_LM"))`, then cast every trainable parameter to `precision.adapter` (AdamW state follows the parameter dtype); if `gradient_checkpointing`: `gradient_checkpointing_enable(gradient_checkpointing_kwargs={"use_reentrant": False})`.
- Batching: micro-batches of `micro_batch_size` rows, right-padded with `pad_token_id`, labels -100 on padding; `accum = effective_batch_size // micro_batch_size`; an optimizer step every `accum` micro-batches or at epoch end. Steps per epoch = `ceil(ceil(n_examples / micro_batch_size) / accum)` (152 for the full run).
- Loss: hidden states from `model.get_base_model().model(input_ids, attention_mask).last_hidden_state`; select positions `t` where `labels[t+1] != -100`; logits = `lm_head(h_sel).float()` only there. sft: CE against `labels[t+1]`. distill: same positions from the teacher (computed **first**, under `torch.no_grad()`, with `model.disable_adapter()` when `teacher.adapter` is None, else `model.set_adapter("teacher")` then back to `"default"`; teacher adapter loaded once via `model.load_adapter(path, adapter_name="teacher", is_trainable=False)` after checking its base model); teacher inputs use `teacher.system_prompt`; assert teacher and student label tokens are identical; per-token loss = `divergence(...)`. Every micro-batch loss = sum of per-token losses / total label tokens in the whole optimizer step (token mean across accumulation).
- Optimizer: `torch.optim.AdamW(trainable, lr=o.lr, betas=tuple(o.betas), eps=o.eps, weight_decay=o.weight_decay)`; set each step's lr from `lr_at` (`torch.optim.lr_scheduler.LambdaLR` or by hand); `clip_grad_norm_(trainable, max_grad_norm)` before each step.
- metrics.jsonl, one row per optimizer step: `{step, epoch, loss, lr, grad_norm, n_tokens, step_s, peak_mem_gb}`, where `lr` is the rate used for that step (read before `scheduler.step()`) (`torch.cuda.max_memory_allocated() / 2**30`, 0 on CPU).
- Save `adapter_ep<e>` after each epoch (1-based) and `adapter` at the end (`save_pretrained`). Summary: `{n_rows_available, n_examples, steps, first_loss, final_loss, train_s, peak_mem_gb}`.
