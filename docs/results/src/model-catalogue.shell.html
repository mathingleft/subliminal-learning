Open-Weight Model Catalogue

Every open-weight family that could serve as a teacher/student pair for the owl/cat and backdoor experiments. For each model: sizes; whether base, instruct and quantized versions exist; architecture; licence; whether it fits one 48 GB L40S; whether its chat template inserts a default system prompt; and how open its training data is. A research agent compiled it from Hugging Face model pages, raw chat templates and the vLLM 0.32 registry. I re-checked the ten shortlisted repos against the Hugging Face API: all exist, with the licences and gating shown. Many entries are newer than my own training data, and cells marked (?) could not be verified.

Shortlist for this project

Ranked by fit on one L40S, a public base and instruct pair, not Qwen, open data, a different architecture, and how the chat template behaves.
